A small Node program that writes a two-line robot apology to `/output/entry.txt`: one sentence owning a very specific household mistake — shredding a handwritten recipe book with the junk mail — and one sentence naming the lesson it draws from that exact slip. No dependencies, fully deterministic output.

## Run it

```sh
node main.ts
```
